LESGO GPU Port Refactor Summary

Build, validation, and case-running guidance for the public GPU-porting package.

Branch prepared from the verified Derecho worktree on 2026-06-06.

Purpose

This branch captures the current verified GPU-port refactor of LESGO. The work keeps timestep data resident on the GPU, reduces managed-memory migration, uses persistent device buffers, and validates each major module change against short controlled LESGO runs.

Main Refactor Themes

Explicit Device Residency

Added device-resident mirrors and shadow arrays for hot ATM data so active kernels can avoid repeatedly dereferencing managed derived-type components.

GPU-Aware Communication

Preserved CUDA-aware MPI paths and moved selected pack/unpack operations onto persistent device buffers.

Compatibility Paths

Kept the legacy CPU/CUDA-managed routes available so existing LESGO users can compare against familiar behavior.

Validation First

After each accepted slice, the branch was rebuilt and checked with short 1-GPU and 2-GPU ATM validation jobs.

Case Build And Submission

Each public case has one compile-only file and one run-only PBS file:

cd test-cases/channel_flow
./compile_derecho.sh
qsub submit_derecho.pbs

The GPU count is controlled by the PBS resource line, the MPI launch variables, and nproc in lesgo.conf.

TargetPBS resource lineMPI launch valueslesgo.conf
1 A100 GPU#PBS -l select=1:ncpus=32:mpiprocs=1:ngpus=1:mem=120gb:gpu_type=a100MPI_RANKS=1, MPI_PPN=1nproc=1
